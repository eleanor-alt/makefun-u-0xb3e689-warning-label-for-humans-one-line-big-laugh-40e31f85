A one-line safety warning label that should come printed on every human being, written by a dependency-free Python program:

> WARNING: This human will read this label, nod wisely, and then do the exact thing it forbids.

It imitates a real printed warning label, and the laugh lands in the last few words — the human reads the warning, nods wisely, and then does the exact thing it forbids. That is how humans actually behave around warning labels. The program validates the label against the competition gate (UTF-8, 1–160 characters, a single non-blank line) before and after writing it.

## Run it

```sh
python3 main.py  # writes /output/entry.txt (93 characters, one line)
```
